# 드라이브스루 응대

## 주문받기
1. 차량이 주문 위치에 서면 5초 안에 인사한다. "안녕하세요, 주문 도와드리겠습니다."
2. 손님 말을 끊지 않고 끝까지 듣는다.
3. 주문이 끝나면 화면에 뜬 주문 내용을 처음부터 다시 읽어 확인한다.
4. 결제 금액을 안내하고 "앞으로 이동해 주세요"라고 말한다.

## 결제와 전달
- 결제 창구에서는 금액을 다시 말하고, 카드는 두 손으로 받아 결제 후 바로 돌려준다.
- 전달 창구에서는 봉투를 열어 주문 내용과 맞는지 확인한 뒤 건넨다.
- 음료는 뚜껑이 잘 닫혔는지 확인하고 캐리어에 담는다.
- 빨대, 소스, 냅킨이 빠지지 않았는지 확인한다.

## 대기가 길어질 때
- 준비에 3분 이상 걸리는 주문은 손님에게 옆 대기 공간으로 이동을 부탁하고 직접 가져다준다.
- 대기 차량이 5대를 넘으면 매니저(점장)에게 알려 인원을 지원받는다.

## 자주 하는 실수
- 주문 확인 없이 바로 결제로 넘어가는 것. 실수의 대부분이 여기서 생긴다.
- 봉투를 확인하지 않고 건네는 것. 차량이 떠나면 바로잡기 어렵다.
