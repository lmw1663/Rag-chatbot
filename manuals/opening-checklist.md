# 오픈 준비 체크리스트

## 언제 하나
- 영업 시작 1시간 전에 오픈 담당 2명이 출근해 시작한다.
- 오픈 담당은 전날 마감 인수인계 노트를 가장 먼저 읽는다.

## 출입과 보안
1. 출입문을 열고 보안 경보를 해제한다. 해제 후 30초 안에 코드를 입력하지 않으면 경보가 울린다.
2. 매장 안을 한 바퀴 돌며 밤사이 이상(누수, 깨진 물건, 고장 표시등)이 없는지 확인한다.
3. 이상이 있으면 사진을 찍고 매니저(점장) 단톡방에 바로 공유한다.

## 기기 켜기 순서
1. 환기 후드를 가장 먼저 켠다. 후드를 켜기 전에는 튀김기(프라이어)와 그릴을 켜지 않는다.
2. 튀김기, 그릴, 보온 장비를 켠다. 튀김기는 설정 온도까지 올라오는 데 약 20분 걸린다.
3. 음료 기계와 커피 머신을 켜고 첫 잔은 버린다.
4. POS와 주문 키오스크를 켜고 영수증 용지가 충분한지 확인한다.

## 온도와 재료 확인
- 냉장고, 냉동고 온도를 확인하고 온도 기록지에 적는다. 기준은 '식품 온도 관리' 매뉴얼을 따른다.
- 오늘 유통기한이 끝나는 재료가 있는지 확인하고, 있으면 폐기 기록 후 버린다.
- 소스, 컵, 포장재 같은 소모품을 영업 시작 전에 채운다.

## 오픈 직전 최종 점검
- 바닥에 물기가 없는지, 매장 테이블이 닦여 있는지 확인한다.
- 화장실 휴지와 손 세정제를 채운다.
- 오픈 체크리스트에 담당자 이름과 시간을 적고 서명한다.

## 이럴 땐 매니저에게
- 기기가 켜지지 않거나 냉장고 온도가 기준을 벗어났을 때
- 보안 경보 코드가 맞지 않을 때
