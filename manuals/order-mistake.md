# 주문 실수 처리

## 실수를 알아챘을 때 (손님이 받기 전)
1. 바로 다시 만든다. 잘못 만든 음식은 손님에게 내보내지 않는다.
2. 대기가 길어지면 손님에게 "주문을 다시 확인하느라 1~2분 더 걸립니다"라고 미리 알린다.
3. 잘못 만든 음식은 폐기 기록지에 사유를 "주문 실수"로 적고 버린다.

## 손님이 받은 뒤 알려줬을 때
1. 먼저 사과한다.
2. 영수증으로 원래 주문을 확인한다.
3. 맞는 메뉴를 다시 만들어 준다. 이미 받은 잘못된 메뉴는 회수한다.
4. 손님이 떠난 뒤 전화로 알려온 경우에는 매니저(점장)에게 넘긴다.

## 결제 실수
- 금액을 잘못 결제했으면 매니저에게 알려 결제를 취소하고 다시 결제한다.
- 직원(크루, 알바) 혼자 결제 취소를 하지 않는다. 취소 처리 방법은 '결제와 환불' 매뉴얼을 따른다.

## 실수를 줄이는 방법
- 주문을 받으면 화면의 주문 내용을 손님에게 다시 읽어 준다.
- 커스텀 요청(빼기, 추가)은 주문서에 표시하고 주방에 말로도 전달한다.
- 포장 전에 영수증과 실제 음식을 한 번 더 맞춰본다.
