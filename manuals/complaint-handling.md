# 컴플레인 응대

## 기본 태도
- 손님 말을 끊지 않고 끝까지 듣는다.
- 변명보다 먼저 사과한다. "불편을 드려 죄송합니다."
- 혼자 판단이 어려우면 "확인해서 바로 도와드리겠습니다"라고 말하고 매니저(점장)를 부른다.

## 응대 순서
1. 듣기: 무엇이 문제인지 정확히 파악한다.
2. 사과: 잘잘못을 따지기 전에 불편에 대해 사과한다.
3. 해결: 아래 기준에 맞게 다시 만들어 주거나 환불한다.
4. 확인: "다른 불편한 점은 없으신가요?"라고 묻는다.
5. 기록: 컴플레인 기록지에 내용과 조치를 적는다.

## 직원이 바로 해결해도 되는 것
- 음식이 식었거나 잘못 만들어졌을 때 같은 메뉴를 다시 만들어 준다.
- 빠진 메뉴나 소스를 바로 챙겨 준다.

## 매니저가 해결해야 하는 것
- 환불이나 금액 조정이 필요한 경우
- 이물질이 나왔다는 컴플레인. 해당 음식은 버리지 말고 보관한다.
- 손님이 화를 내며 언성을 높이는 경우
- 몸이 안 좋아졌다는 컴플레인

## 하면 안 되는 것
- 손님과 언쟁하거나 다른 직원(크루, 알바) 탓을 하는 것
- 손님 앞에서 동료에게 컴플레인 내용을 농담처럼 말하는 것
